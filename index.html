Keyboard shortcuts

SpaceStart / pause scrolling (or listening)
VSwitch between timed scroll and follow-my-voice
↑ ↓Faster / slower
← →Jump back / forward a few lines
PgUp PgDnJump a full screen (presentation clickers work too)
HomeBack to the top
RStart / stop recording
EscCancel the countdown · close dialog
+ −Bigger / smaller text
EEdit script & settings
TShow takes
HHide / show controls
FFullscreen

While recording, only Space, arrows, R, H and Esc work, so a stray key can’t interrupt a take. Mouse wheel / trackpad also scrolls the script. Keep the box at the top of the screen so your eyes stay close to the camera.
